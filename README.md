# User-Management-Api
A user management REST API built with C#, ASP.NET Core Web API, and MySQL to manage user accounts, authentication, passwords, and user details.
# UserManagementAPI

A RESTful API built using C#, ASP.NET Core Web API, and MySQL for user management.

## Features

* User account management
* Login and logout
* Password management
* User details retrieval
* MySQL database integration

*Note: Keep only the features implemented in the current code.*

## Technologies Used

* C#
* ASP.NET Core Web API
* MySQL
* Visual Studio 2022

## Getting Started

1. Clone the repository.
2. Open the project in Visual Studio 2022.
3. Configure the database connection securely.
4. Create the required database and tables.
5. Run the API and test the endpoints.

## Project Purpose

This project demonstrates REST API development, backend programming, and relational database integration using .NET.
